# Changelog

Release notes for the published library now live with the package and
are generated by [changesets](https://github.com/changesets/changesets):

- **[packages/jsx-runtime/CHANGELOG.md](packages/jsx-runtime/CHANGELOG.md)** — `@ui5-community/jsx-runtime` (the npm package).

The showcase (`@ui5-community/jsx-runtime-showcase`) is not published; it
deploys to GitHub Pages and is not versioned.

To propose a release note, add a changeset in your PR (`pnpm changeset`,
or `pnpm changeset:auto`); see [.changeset/README.md](.changeset/README.md)
and the "Releasing" section of [CONTRIBUTING.md](CONTRIBUTING.md).

> Earlier hand-maintained history (pre-changesets) is preserved in git.
