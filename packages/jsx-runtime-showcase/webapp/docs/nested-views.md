# Nested views & embedding

Six patterns for composing reusable UI, ordered from lightest
to heaviest. **Reach for the lightest one that works.** Every
step up buys reusability at the cost of ceremony.

| # | Pattern | Use when |
|---|---|---|
| 1 | JSX fragment `<>…</>` | Grouping siblings, no wrapper. |
| 2 | Helper function returning a control tree | Pieces are local to this view. |
| 3 | `*.fragment.tsx` factory | Controller-callable dialog fits. |
| 4 | Nested TSX `<View/>` | Piece deserves its own lifecycle. |
| 5 | `XMLView({ definition })` | XML is generated at runtime. |
| 6 | `XMLView({ viewName })` | Piece is an on-disk `.view.xml`. |

## 1. JSX fragment

Zero footprint. See [Fragments](#/learn/fragments).

## 2. Helper function

A plain function returning a JSX subtree. Composed at the value
level (`{helper(...)}`, never `<Helper/>`):

```tsx
function statCard(label: string, value: string): Control {
    return (
        <Panel class="sapUiTinyMargin">
            <VBox class="sapUiSmallMargin">
                <Text text={label}/>
                <Title text={value} level="H4"/>
            </VBox>
        </Panel>
    );
}

<HBox wrap="Wrap">
    {statCard("Loaded", "1,284")}
    {statCard("Errors", "0")}
</HBox>
```

## 3. Fragment factory

`*.fragment.tsx` file exporting a factory. Mounted via
`view.addDependent(factory())`. Full story in
[Fragments: sense 2](#/learn/fragments#sense-2-ui5-fragment-factories-fragment-tsx).

## 4. Nested TSX View

Import another view and drop it in:

```tsx
import HelloView from "./Hello";

<Panel headerText="Embedded chapter 1">
    <HelloView async={true} />
</Panel>
```

Own lifecycle, own `byId` scope, own (optional) controller. Its
`id` starts a fresh namespace inside the parent. This is how the
showcase's own Explorer mounts every chapter.

## 5. `XMLView({ definition })`

Inject a `sap.ui.core.mvc.View` built from an XML string at
runtime. Best for XML generated by a plugin or from
`sap.ui.fl`:

```tsx
async createContent(): Promise<Control> {
    const xmlView = await XMLView.create({
        definition:
            '<mvc:View xmlns="sap.m" xmlns:mvc="sap.ui.core.mvc">' +
            '  <VBox><Text text="From XML"/></VBox>' +
            '</mvc:View>'
    });
    return <Panel>{xmlView}</Panel>;
}
```

Any `sap.ui.core.mvc.View` is a `Control`, so it drops into JSX
via `{...}`.

## 6. `XMLView({ viewName })`

Load a `.view.xml` file from disk:

```tsx
const xmlView = await XMLView.create({
    viewName: "my.app.view.EmbeddedByName"
});
```

The view lives at `webapp/view/EmbeddedByName.view.xml`. Best
for coexisting with an XML-view codebase.
